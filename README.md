# 💻 Danilo Kovacs - Site Pessoal

Site pessoal em português e inglês apresentando experiências profissionais, stack tecnológica e projetos acadêmicos desenvolvidos como engenheiro de software.

## 🌐 Visitar o Site

O site está disponível em: [danilokovacs.github.io](https://danilokovacs.github.io)

## ✨ Características

- **Tema Claro/Escuro**: Toggle de tema com persistência via localStorage e suporte a preferências do sistema
- **Internacionalização (i18n)**: Suporte completo a Português e Inglês com toggle de estilo slider
- **Design Responsivo**: Layout adaptativo para desktop, tablet e mobile
- **Acessibilidade**: Suporte a navegação por teclado, leitores de tela e redução de movimento
- **Performance**: CSS otimizado com unidades responsivas e sem dependências externas (exceto fontes)

## 🛠️ Tecnologias

- **HTML5**: Estrutura semântica
- **CSS3**: Variáveis CSS, Flexbox, Media Queries, Animações
- **JavaScript Vanilla**: Manipulação de DOM, localStorage, Event Listeners
- **Google Fonts**: Inter (texto) e JetBrains Mono (código)
- **SVG**: Ícones inline para melhor performance
