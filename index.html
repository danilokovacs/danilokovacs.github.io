📊 Mart

2º SEM - SPTECH School 👨‍🎓

Mart é uma solução para o monitoramento de totens de fast food.

Monitoramento via EC2 na AWS capturando dados de CPU, RAM, disco e sistema para simulação de totens de autoatendimento com alertas e notificações em tempo real.

Tecnologias utilizadas:

Git GitHub Java CLI/GUI Shell Docker MySQL SQL Server Azure HTML/CSS/JavaScript Node.js Scrum Kanban Planner
